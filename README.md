# Money Track – Personal Expense Tracker

**Course:** Mobile Application Design and Development (01418342)

Money Track is an Android application designed to help users manage and track their personal income and expenses. It allows users to record financial transactions, organize them into categories, view transaction history, and monitor spending through a dashboard.

## Features

- **Login:** User authentication.
- **Home:** Overview of personal financial information.
- **Transaction:** Add and manage income and expense records.
- **Categories:** Organize transactions into categories such as Salary, Food, and Transportation.
- **Dashboard:** Visualize income, expenses, and spending summaries.
- **History:** View previous financial transactions.
- **Edit Profile:** Update personal information.

## Technologies

- Kotlin
- Android Studio
- Firebase
- Repository Pattern

## Objective

To develop a mobile application for personal finance management while gaining practical experience in Android development, UI design, cloud database integration, and software architecture.
